# Beginner Login Project

This is a simple login system made by a beginner studying Back-End.

## Technologies

- Python 3 (Main language)
- JSON (Data storage)
- Git/GitHub (Version control)

## How it works

- **Login:** You can log in by providing your name and password.
- **Sign up:** If you don't have an account, it will ask for your name, a characteristic, and a password.
- **Data:** It starts with initial data, but when you sign up, it saves the new user in `dataFile.json`.

## Project Structure

- **Index:** Run this file to start the program. It executes the main login system and prompts user input.
- **Create:** If you don't have an account, it creates one using the `register_fun()` function.
- **Data:** Handles creating and saving data. It manages the JSON file and saves everything there.

## How to Run

**Clone repository command:**
```bash
git clone https://github.com/kauaokamoto/Login.git
```
and run the program.
